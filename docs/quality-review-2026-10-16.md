# 功能检查与 UI 优化记录（2026-10-16）

本轮基于 Windows、egui/eframe 0.29.1 进行代码检查、自动测试及原生窗口观察。保持现有 Robo3T 浅色界面风格，没有升级 GUI 框架。

## 修复

- Find 和聚合查询改为后台执行，完成后唤醒 UI；工具栏显示执行状态，“停止”可取消客户端任务。新查询会取消前一项查询，结果按原始标签 ID 回填，关闭标签后丢弃结果。取消不承诺终止服务器已经执行的命令。
- 开始查询时清除旧结果，避免修改集合脚本后对旧文档执行编辑操作。
- 修复关闭左侧标签导致活动标签改变、关闭其他标签丢失最新编辑、脚本修改标记判断无效、分页输入未随标签恢复等问题。
- 标签右键操作作用于被点击的标签；新建 Shell 前保存当前工作区；欢迎标签禁止中键关闭。
- 成功切换连接时清理旧连接工作区；连接失败时保留原服务和 SSH 隧道；修复欢迎标签 ID 未递增。
- JSON 导出使用标准 canonical Extended JSON，保留日期、ObjectId、Int64 等类型，遇到序列化错误不再静默跳过文档。
- 修复 Timestamp 出现在 ISODate 前无法解析、字符串内构造器文本被误改、时间戳数值越界、日期占位符误改普通字符串和超范围日期无法往返。
- 修复 IPv6 主机解析与 URI 格式、URI 查询参数转义，以及客户端 TLS 证书与 CA 文件不能同时生效。
- 文件菜单的打开/保存复用工具栏实现；实现全屏切换；尚无实现的另存为与旋转按钮禁用。

## UI

- 修复浅色表头与强调文字显示为白色的问题，调整活动控件配色及主操作按钮对比度。
- 欢迎页提供突出显示的连接入口并支持滚动。
- 窄工作区的输出控件分行，连接信息允许换行，显示查询反馈；标签标题截断使用省略号。聚合模式和查询执行期间禁用 Find 分页控件。
- 资源管理器设置合理宽度上下限，并显示当前集合选中状态。
- 状态栏固定到窗口底部；树节点展开状态按标签隔离。
- 保留既有浅色主题；未新增深色主题。

## 验证

- `cargo test --workspace --all-features`：45 项通过（原有 31 项，新增 14 项）。
- `cargo clippy --workspace --all-targets --all-features -- -D warnings`：通过。
- `cargo fmt --all --check`：通过。
- `git diff --check`：通过。
- 新增无窗口渲染测试覆盖 Table/Tree/Text/Custom 四种视图、640×480 逻辑基准尺寸、100% 和 150% 缩放。该测试验证渲染路径可运行，不替代逐像素布局验收。
- 使用 computer-use 技能观察了原生欢迎页、集合浏览与查询表格，并据此定位表头颜色问题。没有对已有数据库执行写入或删除操作。

## 尚未完成的覆盖与已知限制

- 未配置隔离 MongoDB/SSH 测试服务，没有自动化验证真实 CRUD、索引/用户管理、导入写入、SSH 认证/TLS 证书、Atlas、集群或 MongoDB 各版本兼容性。
- 连接、数据库/集合枚举、CRUD、管理命令及文件导入导出仍有同步路径，慢网络或大文件时可能阻塞 UI；本轮后台化覆盖 Find 与聚合查询。
- 聚合目前一次性返回结果，分页控件仍针对 Find；另存为、结果旋转尚未实现。
- 未完成全部弹窗键盘导航、屏幕阅读器和最终所有界面的截图对比；没有深色主题视觉验收。
- 全工作区通过 rustfmt，并清理 Clippy 警告，因此部分文件仅包含格式或等价写法调整。

不能将本轮通过的自动测试理解为“所有功能和所有服务器版本均已端到端验证”。
